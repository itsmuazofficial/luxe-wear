# Luxe-wear

A responsive e-commerce clothing website built with React.

**Live Demo: luxe-wear-nu.vercel.app/

## Features
- Home, Shop, Category, About and Contact pages
- Add to cart functionality
- Client-side routing with React Router DOM
- Responsive design for mobile and desktop

## Tech Stack
- React
- React Router DOM
- HTML, CSS, JavaScript

## Run Locally
1. Clone the repo: `git clone https://github.com/itsmuazofficial/luxe-wear`
2. Install packages: `npm install`
3. Start the app: `npm run dev`
